### 2026-11-21 (user data objects and places — interviewed, edges ruled, planned, reviewed) — plan only, no code; nothing deployed

**Outgoing handoff carried:** the 11-21 primer named this as the next planning item
(`archive/handoffs/2026-11-21-custom-logs-and-places-planning-prompt.md`); goal–task network
phase 2 was building in a parallel window throughout.

**Scope widened by Mike, deliberately.** "Custom logs" became **user data objects**: *"Lists and
logs are not separate things… form follows function"*, and *all* user data — wisdom, contacts,
places/zones, day shape, tasks — counts, not just new objects. Thirty-four rulings, attributed in
plan § 2. The load-bearing ones: writes land **just after the reply** (overnight rejected as too
late); unasked objects are created and announced, **but ASKED via a confirmation card while only
development users exist** (R34); promotion = a template every user has; nothing is ever deleted,
only archived/hidden; places carry a verdict **and the occasion it is for** — relevance, not
nearness, triggers a mention (*"108 Brasserie is only good if scheduling a meal"*); routine places
are logged as visits, kept forever; background location built in, optional, default off, behind a
versioned consent record; Pattern Miner gets all user data; others overhearing is the user's risk.

**The 2026-08-28 location ruling is amended (R24, R33):** a recurring unnamed spot may be held as a
~100 m rounded point with counts after a minimum stay, and one rounded last position is kept,
overwritten per report. Coordinates still never reach a prompt; reverse geocoding stays refused.

**Rejected:** merging every store into one (Mike: *"general procedure is default only if there's no
specialty governance"* — existing stores are registered, not moved, and their own write tools keep
their protections); a model judging object similarity across users (mingles two users in one
prompt); a shadow review list before unasked creation (asking measures and serves at once);
reverse geocoding the user's position.

**Wrong in the first draft, found by the Fable adversarial review (6 structural + 4 local):** the
top finding — registering films/books as "thing + occurrences" would have turned agents' habit of
filing a book twice (at mention, at completion), which today's merge silently absorbs, into two
false readings. Also: phase 1 could not be live-checked (its writer was in phase 2); the geofence
feed bypassed the consent gate; making places zones would have sent the day planner's start point
silently back to `home`; the registry sat where `write_archive` could overwrite it; the common read
tool widened every agent's reach. Verify round: 8 closed, 2 reshaped, 3 new (Pattern Miner's grants
unlisted; stay detection impossible on a movement-triggered feed; the offer's answer tied to reply
wording — the redo-question trap). All revised the same day, **not re-verified**; the phase 1 and
phase 4 diff reviews own them.
